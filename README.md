## Tentang ZeroneXCode

ZeroneXCode mengembangkan dan memelihara proyek installer ini untuk memudahkan pemasangan tema Pterodactyl melalui menu terminal. Proyek ini mencakup penyesuaian kompatibilitas, perbaikan alur instalasi, serta integrasi pengaturan tema.

## Pembaruan dan bantuan

Informasi versi dan perubahan proyek akan diumumkan melalui channel resmi. Jika menemukan kendala, hubungi admin dengan menyertakan:

- Nama tema yang dipilih.
- Versi panel Pterodactyl.
- Pesan error atau tangkapan layar terminal.
- Langkah yang dijalankan sebelum kendala muncul.

Jangan sertakan password, token akses, isi `.env`, atau kredensial server dalam laporan publik.
